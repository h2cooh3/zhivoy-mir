# Живые голоса для «Живого мира» — подключение Yandex SpeechKit

Один раз, минут 15. Дальше в «Книге» нажимаешь «🎙 Озвучить живыми голосами». Аудио сохраняется в телефоне: его можно слушать офлайн и с выключенным экраном, а можно скачать одним mp3.

Цена: около **0,16 ₽ за 250 символов**. Час аудио обходится примерно в 36 ₽.

## 1. Аккаунт и оплата
1. Зайди на https://console.yandex.cloud и войди через Яндекс ID.
2. Создай **платёжный аккаунт** и привяжи карту. Если карта не проходит, попробуй казахстанскую или российскую.
3. Яндекс сам создаст **облако** и **каталог** `default`. Открой каталог и скопируй его **ID** из строки под названием (выглядит как `b1g…`). Это **FOLDER_ID**.

## 2. Сервисный аккаунт (чтобы ключ не хранить в приложении)
1. В каталоге: **Identity and Access Management → Сервисные аккаунты → Создать**.
2. Имя: `tts`. Роль: **`ai.speechkit-tts.user`**. Создать.

## 3. Облачная функция
1. В каталоге: **Cloud Functions → Создать функцию**. Имя: `tts`.
2. Включи переключатель **«Публичная функция»**, чтобы приложение могло её вызывать.
3. **Редактор → Node.js 22** (или 18). Создай файл `index.js` и вставь туда весь код из [`index.js`](index.js) рядом с этой инструкцией.
4. Настройки версии:
   - Точка входа: `index.handler`
   - Таймаут: `30` секунд
   - Память: `128 МБ`
   - Сервисный аккаунт: `tts`
   - Переменные окружения:
     - `FOLDER_ID` = ID каталога из шага 1
     - `SECRET` = любое слово-пароль (например, `frey4-shtorm`), чтобы чужие не тратили твои деньги
5. **Сохранить изменения**. Наверху появится **ссылка для вызова** вида `https://functions.yandexcloud.net/d4e…`. Скопируй её.

## 4. В приложении
**Настройки → Живые голоса**:
- **Адрес функции**: ссылка из шага 3.
- **Пароль функции**: то же слово, что в `SECRET`.
- **Голос рассказчика**: выбери.
- Нажми **«▶ Проверить голос»**. Если услышал фразу про шторм, всё работает.

Персонажам голоса раздаются автоматически: женщинам женские, мужчинам мужские, всем разные. Голос рассказчика персонажам не достаётся.

## Если что-то не так
- **«Пароль функции не совпадает»**: слово в приложении не совпадает с `SECRET`.
- **«no service account»**: в настройках функции не выбран сервисный аккаунт.
- **403 / Permission denied от Яндекса**: у сервисного аккаунта нет роли `ai.speechkit-tts.user`.
- **401 / function is not public**: не включена «Публичная функция».
