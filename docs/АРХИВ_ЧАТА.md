2. Key Technical Concepts:
   - Single-file index.html app, with state `S` (worlds, chars, scenes, api, sync). Storage is IndexedDB/localStorage. The service worker sw.js uses network-first fetching with cache name `zhivoymir-vN`, which is bumped on every release.
   - Characters use accessor properties (history, summary, sumIdx, dirIdx, dramaIdx, guests, drama) that map to the active chat in `c.chats` (`wireChar`).
   - Sync goes through a GitHub gist and is merge-based:
     - a `rev` id per push and a `S.sync.dirty` flag;
     - the push first pulls and merges, keeping the newer `updated` per world/char/scene;
     - large data is read from `raw_url` without the Authorization header;
     - errors are shown in the status line and as a toast.
   - Story engine on `w.story`:
     - `acts`, `events` (`day:[a,b]`, optional `if` flag), `flagDefs`, `endings` (`minDay`), `quests`, `tales`;
     - state: `day`, `part`, `act`, `flags`, `questState`, `questRes`, `questEnd`, `questStart`, `talesTold`, `echoed`, `pending`, `done`, `ending`, `opening`, `openCast`, `startPart`, `patches`;
     - `storyTick` is a cheap-model keeper that runs every 2 replies;
     - `storyBlock(w,cast)` and `sideBlock` are injected into the prompts;
     - `finishStory` writes the epilogue.
   - Hero as a character: `w.heroId`, with `heroChar`, `heroName`, `heroDesc`, and `npcsOf(wid)` (characters excluding the hero).
   - Main story: a scene with `main:true`. Related functions: `openMainStory`, `mainStoryOf`, `scenePeople`, `autoCast`, `moveChatToMain(w,c)`, `importChatToMain`, `parseChatFile`, `chatFile`, `genName` (genitive case).
   - Addons, keyed by `tplOf(w)`:
     - `presets/addons/*.json` with `worldRulesAdd`, `worldPlacesAdd`, `relAdd`, `charPatch`, `story`, `storyPatch` (`replace`, `id`), `heroName`;
     - each addon is described by an entry in `ADDONS` with `file`, `names`, `storyId` and `patchId`.
   - Maps: `WORLD_MAPS` (arrays), `mapsOf`/`mapOf`, `openMap` with tabs, `mapCard` triggered by `MAP_RX`; `w.map` holds a custom upload.
   - Lore auto-append once: `LOCAL_PLACES` and `NATURE` through `ensureLocalPlaces` (called from `fixAll`).
   - First appearance: `shownOf`, `markShown`, `isNew`, `FIRST_RULE`, `lookCue`, `nameIn`, `nameStem`.
   - Code import (just added): `codeImport` with PBKDF2 + AES-GCM + gzip via `DecompressionStream`.

## Часть 2. Последняя сессия, дословно

### 🤖 Claude

Готово, у мира теперь два названия.

- **Своё название (тема)** — твоё, например «У побережья». На главной оно крупное, по нему копии одного мира различаются.
- **Название мира** — «Южное побережье», мелкой строкой под ним. По этому названию ИИ, карты и дополнения понимают, какой это мир, поэтому его лучше не менять.

Где задать своё название:
- на главной в «⋯» у мира → «✎ Своё название (тема)»;
- или в «Изменить мир», там это первое поле.

Если поле оставить пустым, на главной будет просто «Южное побережье», как раньше. Карты, квесты и дополнения своё название никак не задевает.

Сделал: теперь Фрейю первым видит Эдвин, а не Пип.

**Как теперь начинается ночь шторма.** Уилл выходит на крыльцо. Внизу в бухте мотается один фонарь: Эдвин не спит и стережёт лодку. Это крючок, игрок его видит с первого же текста. Уилл идёт к Чёрным камням и находит девушку. Дальше в сюжете есть событие первого дня: когда Уилл несёт её назад мимо бухты, Эдвин выходит навстречу с фонарём. Он ни о чём не спрашивает, подставляет плечо и помогает донести до дома. У порога говорит одно: «Бесс я скажу, что лодку сорвало». После этого он хранит ещё одну тайну друга.

Это хорошо стыкуется с тем, что уже было:
- Эдвин и так единственный, кто знает прошлое Уилла и никогда о нём не спрашивает.
- Его утреннее приветствие «Бесс мне всю ночь спать не давала…» теперь читается иначе: он вернулся ночью мокрый и соврал жене.
- Пип остаётся первым **из детей**. Утром он замечает её в окне и решает, что это русалка.
