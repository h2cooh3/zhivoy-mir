Живые голоса (Yandex SpeechKit)

Для «Книги»: озвучка настоящими голосами, аудио сохраняется в телефоне — потом слушаешь офлайн, даже с выключенным экраном, и можно скачать mp3. Около 36 ₽ за час аудио. Как подключить — инструкция.

Провайдер, модель, адрес, цены, драматург — одной строкой, чтобы перенести на другое устройство или отдать другу. Ключ — только если сам выберешь. Настройки модели также ездят с синхронизацией GitHub (без ключа).

Расход

Для моделей Claude 5.5 цены подставляются сами (Sonnet: $2 вход, $0,10 из кэша, $10 выход за млн токенов; Haiku: $0,10 / $0,01 / $0,50). Поля ниже — для других моделей и провайдеров.

Ключ хранится только в этом браузере и уходит напрямую провайдеру. Для Anthropic включено кэширование: неизменная часть промпта (мир, характер) при повторной отправке стоит примерно в 10 раз дешевле.

Синхронизация между устройствами

Телефон и компьютер хранят данные по отдельности. Чтобы видеть одно и то же, приложение может держать копию в твоём GitHub (приватный гист, который видишь только ты). Нужен токен GitHub с правом на гисты.

Сохранения мира

Слепок всех миров и персонажей. Пошло не туда — загрузись и попробуй иначе.

Резервная копия в файл

«Загрузить» понимает любой файл приложения: полную копию, один мир с персонажами или одного персонажа. Персонажей и миры по отдельности можно сохранить из их экрана.

Данные хранятся на этом устройстве. Ключ в файл не попадает.
